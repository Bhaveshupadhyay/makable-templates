# John Doe - 3D Developer Portfolio

This directory contains a standalone, zero-dependency static 3D developer portfolio template featuring interactive Three.js avatar animations, dynamic project showcase, and a responsive interface.

---

## Quick Start (Run Locally Without Node.js)

To preview the website locally without Node.js or npm, use either of the included runners:

### Option 1: Python 3
```bash
python3 serve.py
# or: python3 -m http.server 8080
```
Open [http://localhost:8080](http://localhost:8080) in your browser.

### Option 2: Shell Script (auto-detects Python 3 or Bun)
```bash
./serve.sh
```

---

## Features

- **John Doe Placeholder**: All copy, mail, names, and social links are fully sanitized and configurable.
- **Zero Node.js Runtime**: Runs entirely on client-side WebAssembly, Three.js, and static bundles.
- **No Build Step Required**: Ready to host on GitHub Pages or any static CDN.
